## Descripción

PaginaWebTest es una aplicación web demostrativa que permite controlar visualmente un indicador circular mediante dos modos de funcionamiento:

- **Modo Verde**
- **Modo Azul**

El indicador inicia en color gris y cambia dinámicamente según el modo seleccionado.

El proyecto tiene como finalidad demostrar de forma práctica el flujo completo definido por la **Metodología del Proyecto Profesional v3.0.0**.

---

## Funcionalidades

La versión 0.1.0 incluye:

- Página web de una sola página.
- Indicador circular tipo LED.
- Estado inicial gris.
- Cambio a Modo Verde.
- Cambio a Modo Azul.
- Diseño responsive básico.

---

## Tecnologías

La versión 0.1.0 utiliza exclusivamente:

- HTML5
- CSS3
- JavaScript Vanilla

No utiliza:

- Frameworks.
- Librerías externas.
- Backend.
- Base de datos.
- Persistencia de datos.

---

## Compatibilidad

La versión 0.1.0 soporta oficialmente:

- Google Chrome.
- Microsoft Edge.

Mozilla Firefox no forma parte del alcance oficial de la versión 0.1.0.

## Arquitectura

La aplicación utiliza una arquitectura cliente única, separando la estructura, presentación y comportamiento:

```text
HTML5
  └── Estructura

CSS3
  └── Presentación

JavaScript Vanilla
  └── Comportamiento
```
