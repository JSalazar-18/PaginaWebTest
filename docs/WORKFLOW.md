# WORKFLOW — PaginaWebTest

## 1. Propósito

Este documento define el flujo de trabajo general utilizado para gestionar PaginaWebTest.

El objetivo es establecer una secuencia clara de trabajo entre las diferentes actividades y los seis chats especializados del proyecto.

---

## 2. Principio general

El trabajo debe realizarse de forma controlada y trazable.

Cada actividad debe utilizar como referencia los documentos existentes del proyecto y mantenerlos actualizados cuando corresponda.

El **Chat 00 — Gestión del Proyecto** actúa como centro de coordinación.

---

## 3. Estructura de chats

El proyecto utiliza seis chats especializados:

```text
00 - Gestión del Proyecto
01 - Arquitectura
02 - Desarrollo
03 - Pruebas
04 - Documentación
05 - Git y GitHub
```
