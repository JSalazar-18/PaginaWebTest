# PROJECT LIFECYCLE — PaginaWebTest

## 1. Propósito

Este documento define el ciclo de vida utilizado para gestionar el proyecto PaginaWebTest.

El ciclo de vida establece las fases generales por las que pasa el proyecto y las condiciones necesarias para avanzar entre ellas.

---

## 2. Principio general

El proyecto se desarrolla de forma controlada y trazable.

Cada fase debe producir los documentos y resultados necesarios antes de avanzar a la siguiente.

El Chat 00 — Gestión del Proyecto actúa como centro de coordinación y controla el avance general.

---

## 3. Fases del proyecto

El ciclo de vida general es:

```text
Planificación
      ↓
Requisitos
      ↓
Arquitectura
      ↓
Desarrollo
      ↓
Pruebas
      ↓
Documentación
      ↓
Git y GitHub
      ↓
Release / Publicación
```
