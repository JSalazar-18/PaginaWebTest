# 1. Objetivo

Definir y controlar las iteraciones del proyecto PaginaWebTest, estableciendo el alcance, objetivos, criterios de aceptación, estado y criterios de cierre de cada iteración.

Este documento constituye la referencia oficial para determinar si una iteración está planificada, en ejecución, cerrada o cancelada.

---

# 2. Principios de Gestión de Iteraciones

Las iteraciones se gestionan bajo los siguientes principios:

1. Cada iteración debe tener un objetivo definido.
2. El alcance debe estar identificado antes de iniciar el desarrollo.
3. Los requisitos correspondientes deben estar documentados.
4. Las decisiones relevantes deben quedar registradas.
5. Las pruebas deben ejecutarse antes del cierre.
6. La documentación debe mantenerse sincronizada.
7. El versionado debe corresponder al incremento entregado.
8. Una iteración solo puede considerarse cerrada cuando cumple sus criterios de cierre.
9. Chat 00 – Gestión del Proyecto es responsable de autorizar formalmente el inicio y cierre de las iteraciones.
10. No se deben ejecutar cambios de alcance sin autorización formal.

# 4. Iteración 1 – MVP y Base Metodológica

## 4.1 Objetivo

Construir y validar un MVP funcional de PaginaWebTest y establecer la base metodológica, documental y técnica del proyecto.

El MVP debía permitir:

- Mostrar un indicador circular.
- Mostrar el indicador inicialmente en color gris.
- Cambiar el indicador a verde mediante el control correspondiente.
- Cambiar el indicador a azul mediante el control correspondiente.
- Mantener una estructura básica de HTML, CSS y JavaScript.
- Validar el funcionamiento mediante pruebas.
- Documentar la solución.
- Versionar el proyecto mediante Git.
- Publicar la versión inicial en GitHub.
