# 1. Objetivo

Definir la planificación incremental del proyecto PaginaWebTest mediante iteraciones controladas, estableciendo para cada una su alcance, objetivos, entregables, dependencias, criterios de aceptación y criterios de cierre.

Cada iteración deberá generar un incremento funcional del proyecto y mantener sincronizada toda la documentación.

---

# 2. Estrategia de Iteraciones

El proyecto seguirá una estrategia de desarrollo incremental.

Cada iteración finalizará únicamente cuando:

- El desarrollo correspondiente haya concluido.
- Las pruebas hayan sido aprobadas.
- La documentación esté sincronizada.
- Las fases previstas para la iteración hayan sido completadas.
- Las actividades de Git y GitHub hayan sido completadas cuando formen parte de la iteración.
- La publicación prevista haya sido completada cuando forme parte de la iteración.
- El Chat 00 autorice formalmente el cierre de la iteración.

La finalización de las fases individuales no implica por sí misma el cierre de la iteración.
