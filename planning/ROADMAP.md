# 1. Objetivo

Definir la evolución planificada del proyecto PaginaWebTest, estableciendo la visión, las versiones previstas, los objetivos estratégicos, los hitos principales y los criterios de avance que servirán de guía durante todo el ciclo de vida del proyecto.

---

# 2. Visión del Proyecto

PaginaWebTest tiene como finalidad demostrar, mediante un caso práctico, la aplicación completa de la Metodología del Proyecto Profesional v3.0.0.

El proyecto permitirá validar:

- Gestión del proyecto.
- Arquitectura.
- Desarrollo.
- Pruebas.
- Documentación.
- Git y GitHub.

Todo ello utilizando una aplicación web sencilla desarrollada exclusivamente con tecnologías web estándar.

---

# 3. Objetivos Estratégicos

## Corto Plazo

- Completar la planificación del proyecto.
- Diseñar la arquitectura inicial.
- Implementar la versión mínima funcional (MVP).
- Validar el flujo metodológico completo.

---

## Mediano Plazo

- Mejorar la estructura visual.
- Optimizar la organización del código.
- Incrementar la cobertura de pruebas.
- Incorporar mejoras derivadas de las primeras iteraciones.

---

## Largo Plazo

- Obtener una versión estable 1.0.0.
- Disponer de un proyecto completamente documentado.
- Utilizar PaginaWebTest como proyecto de referencia para la metodología.

# 5. Alcance por Versión

## Versión 0.1.0

Incluye:

- Página principal.
- Indicador circular.
- Botón "Modo Verde".
- Botón "Modo Azul".
- HTML5.
- CSS3.
- JavaScript Vanilla.
- Documentación metodológica completa.

No incluye:

- Backend.
- Base de datos.
- Frameworks.
- Persistencia de información.

---

## Versión 0.2.0

Objetivos previstos:

- Mejoras de interfaz.
- Refactorización del código.
- Optimización responsive.
- Mejora de la organización del proyecto.

---

## Versión 0.3.0

Objetivos previstos:

- Nuevos modos del indicador.
- Configuración visual.
- Mejoras de experiencia de usuario.
- Preparación para escalabilidad.

---

## Versión 1.0.0

Objetivos previstos:

- Proyecto estable.
- Cobertura completa de pruebas.
- Documentación final.
- Publicación oficial.
