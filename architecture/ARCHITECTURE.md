# ARCHITECTURE - Arquitectura del Proyecto

**Versión:** 0.1.0

**Última actualización:** 03-08-2026

---

## 1. Objetivo

Definir la arquitectura tecnológica de PaginaWebTest, estableciendo la relación entre los componentes frontend, el almacenamiento de datos y las herramientas de desarrollo.

---

## 2. Capas del Proyecto

### 2.1 Frontend

- **HTML5:** Estructura de las páginas
- **CSS3:** Estilos y diseño responsive
- **JavaScript:** Interactividad y lógica del cliente

### 2.2 Infraestructura

- **Git:** Control de versiones
- **GitHub:** Repositorio remoto
- **ChatGPT Projects:** Entorno de coordinación

---

## 3. Principio de Integración

El proyecto utiliza **ChatGPT Projects** como espacio de trabajo persistente, mientras que los **chats especializados** funcionan como áreas de desarrollo.

**Regla fundamental:** La información importante debe trasladarse a los documentos correspondientes.
