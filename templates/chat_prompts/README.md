# Chat Prompts Oficiales

## Objetivo

Esta carpeta contiene la colección oficial de **Prompts de Inicialización** para los chats especializados utilizados en los proyectos desarrollados bajo la metodología **Manual_Metodologico_Proyecto_Profesional**.

Cada prompt define el rol, las responsabilidades, los límites de actuación y la forma de trabajo de un chat específico dentro de un Proyecto de ChatGPT.

Estos prompts forman parte de la **Plantilla_Proyecto_Profesional** y constituyen la configuración inicial recomendada para todos los proyectos futuros.

---

# Alcance

Esta colección define únicamente la configuración inicial de los chats especializados utilizados dentro de ChatGPT Projects.

No reemplaza la documentación del proyecto, la metodología oficial ni los procesos de desarrollo.

Su finalidad es garantizar que todos los proyectos comiencen con una estructura organizativa uniforme, responsabilidades claramente delimitadas y un flujo de trabajo consistente.

---

# Propósito

Los prompts permiten que todos los proyectos mantengan una organización homogénea, evitando que cada chat sea inicializado de forma diferente.

Cada chat posee una responsabilidad claramente definida, reduciendo la superposición de funciones y facilitando la coordinación entre los distintos aspectos del proyecto.

---

# Organización

Actualmente la colección está compuesta por los siguientes prompts:

| Archivo | Chat | Responsabilidad |
|----------|------|-----------------|
| 00_Gestion_Proyecto.md | 00 - Gestión del Proyecto | Planificación, seguimiento y coordinación general del proyecto. |
| 01_Arquitectura.md | 01 - Arquitectura | Diseño de la arquitectura, tecnologías y decisiones técnicas. |
| 02_Desarrollo.md | 02 - Desarrollo | Implementación del código y desarrollo funcional. |
| 03_Pruebas.md | 03 - Pruebas | Planificación, ejecución y validación de pruebas. |
| 04_Documentacion.md | 04 - Documentación | Elaboración y actualización de la documentación técnica y funcional. |
| 05_Git_GitHub.md | 05 - Git y GitHub | Administración del control de versiones, ramas, commits y repositorio. |

Cada prompt debe utilizarse exclusivamente para el propósito para el cual fue diseñado.

---

# Procedimiento de uso

Para crear un nuevo chat dentro de un Proyecto de ChatGPT:

1. Crear el chat dentro del Proyecto correspondiente.
2. Asignarle el nombre oficial definido por la metodología.
3. Si ChatGPT genera automáticamente un mensaje inicial, ignorarlo.
4. Copiar el contenido completo del prompt correspondiente.
5. Pegarlo como primer mensaje del chat.
6. Esperar que ChatGPT procese completamente el prompt.
7. A partir de ese momento utilizar el chat únicamente para las responsabilidades definidas en dicho prompt.

---

# Flujo recomendado de creación

Los chats deberán crearse siguiendo el siguiente orden:

1. 00 - Gestión del Proyecto
2. 01 - Arquitectura
3. 02 - Desarrollo
4. 03 - Pruebas
5. 04 - Documentación
6. 05 - Git y GitHub

Los chats adicionales deberán incorporarse únicamente cuando el proyecto realmente los requiera.

---

# Reglas generales

Todos los proyectos deberán respetar las siguientes reglas:

- Cada chat tendrá una única responsabilidad principal.
- No duplicar responsabilidades entre chats.
- Mantener la trazabilidad de las decisiones importantes.
- Utilizar siempre la metodología oficial del proyecto.
- Consultar las Fuentes del Proyecto cuando sea necesario.
- Validar cada fase antes de continuar con la siguiente.
- Mantener la coherencia entre todos los chats especializados.

---

# Mantenimiento

Esta colección forma parte de la **Plantilla_Proyecto_Profesional**.

Las modificaciones deberán realizarse siempre sobre la plantilla oficial.

Los proyectos ya iniciados no deberán modificar estos prompts salvo que exista una decisión metodológica formalmente aprobada.

Toda mejora deberá incorporarse primero a la plantilla y posteriormente utilizarse en los nuevos proyectos.

---

# Observaciones

Los prompts de esta colección constituyen la configuración inicial recomendada para cada chat especializado.

Una vez inicializado un chat, éste podrá evolucionar de acuerdo con las necesidades del proyecto, siempre respetando la metodología definida en el **Manual_Metodologico_Proyecto_Profesional**.

La existencia de esta colección no reemplaza la documentación oficial del proyecto ni las responsabilidades de cada uno de los documentos definidos por la metodología.
